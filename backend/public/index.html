🎬 Movie API

Node.js + Express ile yazılmış, dosya tabanlı JSON veritabanı kullanan film API'si. Kurulum gerektirmez, veritabanı projeyle birlikte taşınır. Frontend alıştırmaları için 85 film, 40 kullanıcı, gerçek poster görselleri ve binlerce beğeni/puan/yorum ile hazır gelir.

İlk isteğiniz

// Filmleri puana göre sıralı getir
const res  = await fetch("http://localhost:4000/api/movies?sort=-rating&limit=12");
const json = await res.json();

console.log(json.data);            // film dizisi
console.log(json.meta.pagination); // { page, limit, total, totalPages, hasNextPage, ... }

Giriş yapıp beğenmek

// 1) Giriş yap, token al
const login = await fetch("http://localhost:4000/api/auth/login", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ identifier: "elif", password: "123456" })
}).then(r => r.json());

const token = login.data.token;

// 2) Token ile beğen
await fetch("http://localhost:4000/api/movies/mv_043/like", {
  method: "POST",
  headers: { Authorization: `Bearer ${token}` }
});

Bilmeniz gerekenler

  • Tüm yanıtlar { success, data, meta }, hatalar { success:false, error:{ code, message, details } } formatındadır.
  • Her liste ucu page ve limit ile sayfalanır; meta.pagination içinde sonraki/önceki sayfa bilgisi gelir.
  • Token gönderirseniz filmler isLiked, isFavorite, isInWatchlist, myRating alanlarıyla döner.
  • Herhangi bir isteğe ?delay=1500 ekleyerek yükleniyor (loading) durumlarını test edebilirsiniz.
  • CORS açıktır; frontend'inizi istediğiniz portta çalıştırabilirsiniz.
Veritabanı data/ klasöründeki JSON dosyalarıdır — dosyaları açıp içeriği inceleyebilirsiniz. Film adı, yılı, kadrosu, özeti ve poster görselleri Wikipedia film veri setinden gelir; puan, beğeni ve yorumlar üretilmiş örnek verilerdir.
